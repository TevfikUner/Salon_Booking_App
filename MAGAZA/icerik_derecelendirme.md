# İçerik Derecelendirmesi (IARC anketi) Yanıtları

Play Console → Politika → Uygulama içeriği → İçerik derecelendirmesi → Anketi başlat.

- E-posta: geliştirici hesabı e-postası (IARC sertifikası buraya gelir)
- Kategori: **Diğer tüm uygulama türleri** ("Referans, Haber veya Eğitim" / "Sosyal" / "Oyun" DEĞİL)

| Soru | Yanıt | Not |
|---|---|---|
| Şiddet içeriyor mu? | Hayır | |
| Korku / ürkütücü içerik | Hayır | |
| Cinsel içerik veya çıplaklık | Hayır | |
| Küfür / kaba dil | Hayır | Kullanıcı yorumları var ama yalnızca puan + kısa yorum, salon sayfasında gösterilir — aşağıdaki "kullanıcı içeriği" sorusuna bakın |
| Uyuşturucu, alkol, tütün | Hayır | |
| Kumar / şans oyunları, gerçek para | Hayır | |
| Kullanıcılar birbiriyle etkileşime girebiliyor veya içerik paylaşabiliyor mu? | **Evet** | Müşteriler salon/berber için puan ve yorum bırakabilir; salon müşteriye WhatsApp/telefonla ulaşabilir |
| Kullanıcılar arasında konum paylaşımı | Hayır | Konum yalnızca salon sıralaması için kullanılır, kimseyle paylaşılmaz |
| Kullanıcıların kişisel bilgilerini paylaşması | **Evet** | Randevu alınca ad ve telefon seçilen salonla paylaşılır |
| Dijital mal satın alma | Hayır | Uygulama içi ödeme yok |
| Uygulama bir web tarayıcısı / arama motoru mu? | Hayır | |
| Ağırlıklı olarak haber/eğitim içeriği mi? | Hayır | |

Beklenen sonuç: **3+ / PEGI 3 / Herkes**, "Kullanıcılar etkileşimde bulunur" ve "Kişisel bilgiler paylaşılır" etkileşim
öğeleriyle. Sonuç farklı çıkarsa yanıtları değiştirmeyin; gerçek davranışı yansıtıyorlar.

## Diğer "Uygulama içeriği" beyanları

| Beyan | Yanıt |
|---|---|
| Gizlilik politikası | `https://<API_ADRESİ>/yasal/gizlilik` |
| Uygulama erişimi | "Tüm işlevler özel erişim olmadan kullanılabilir" DEĞİL → **Bazı işlevler kısıtlı**: işletme paneli onaylı işletme hesabı ister. İnceleme için test hesabı verin (bkz. BENDEN_GEREKENLER: inceleme hesabı) |
| Reklamlar | Uygulama reklam içermiyor |
| Hedef kitle | 13–15, 16–17, 18+ |
| Haber uygulaması | Hayır |
| COVID-19 temaslı takip | Hayır |
| Veri güvenliği | `MAGAZA/veri_guvenligi.md` |
| Devlet uygulaması | Hayır |
| Finansal özellikler | Hiçbiri |
| Sağlık | Hiçbiri |
